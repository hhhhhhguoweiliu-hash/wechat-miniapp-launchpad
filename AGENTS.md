# AGENTS.md — WeChat Miniapp Launchpad AI Rules

This repository is a reusable skill/tooling project. User owns product direction; ChatGPT PM coordinates; Codex may maintain, test, and improve the existing skill within low-risk reversible scope.

Before work read `README.md`, `SKILL.md`, `.ai/PROJECT_BOARD.md`, `.ai/NIGHT_SHIFT.md`, `.ai/LEASE.md` and relevant references/scripts.

Rules:
- Preserve the existing six-stage launch workflow unless there is clear evidence of an error.
- Do not silently turn third-party/project-specific tricks into universal facts.
- New product ideas go to IDEA INBOX, not implementation.
- Maintenance, docs consistency, script tests, packaging, and clearly reproducible bug fixes may proceed autonomously.
- No real WeChat account publishing, credentials, paid services, or production actions without explicit user authorization.
- Stable milestones: test, update board/lease, commit, push `codex/night-shift`; never force or auto-merge main.
