# 阶段②：注册小程序账号 + 装开发者工具

## 1. 注册小程序（用户本人操作，约 10 分钟）

1. 打开 <https://mp.weixin.qq.com> → 立即注册 → 选"小程序"。
2. 填邮箱（必须没注册过微信公众平台/微信开放平台的邮箱）→ 激活邮件。
3. 信息登记：
   - **主体类型**：零基础/个人项目选"个人"。个人主体免费，限制是部分类目不能做（医疗、金融、电商交易、社交关系链等），不能做微信支付。
   - 身份证 + 手机号 + 微信扫码刷脸实名。
4. 注册完进入 mp 后台 → 开发管理 → 开发设置 → 复制 **AppID**（形如 `wx****************`）。

**限制要知道**：一个身份证最多注册 5 个个人小程序；一个邮箱只能绑一个账号。

## 2. 装微信开发者工具

- 下载：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>，选**稳定版 Stable Build**，Windows/macOS 都有。
- 微信扫码登录（用注册小程序的那个微信）。

## 3. 创建项目

1. 开发者工具 → 新建 → 小程序项目。
2. 目录选**空文件夹**；AppID 填刚复制的（没 AppID 可选"测试号"，能开发不能上线）。
3. 模板选"不使用模板"（零基础从干净目录开始，AI 生成全部代码）；开发模式"小程序"，后端服务"不使用云服务"（纯本地项目）。
4. 创建后工具会生成示例文件，全部删掉，按 references/project-structure.md 重建。

## 4. 工具常用面板

| 面板 | 用途 |
|---|---|
| 模拟器 | 选机型（iPhone 6/7/8 最常用基准），看页面效果 |
| 编辑器 | 写代码，保存自动编译 |
| 调试器 | Console 看报错/Network 看请求/Sources 断点 |
| 详情→本地设置 | 勾选"不校验合法域名"（仅开发期） |
| 预览 | 生成二维码，真机扫码看真实效果 |
| 上传 | 打包成体验版，填版本号和备注 |

## 5. 成员管理（可选）

mp 后台 → 成员管理 → 添加体验成员：朋友扫码就能玩体验版，不用上架。

## 常见卡点

- **邮箱被占用**：换一个没注册过微信系平台的邮箱（QQ 邮箱新注册一个也行）。
- **AppID 填错**：项目创建后还能改：开发者工具 → 详情 → 基本信息 → AppID。
- **模拟器正常但真机异常**：90% 是用了模拟器不支持的能力（传感器、人脸、震动）或路径大小写问题（真机文件系统区分大小写！引用路径必须和实际文件名大小写完全一致）。
